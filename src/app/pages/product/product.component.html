02 · EVIDENCE VAULT

Cada evento queda en piedra. Imposible de alterar.

El vault aplica hash SHA-256 a cada evento, lo encadena criptográficamente al evento anterior, y lo timestampea con servidor de tiempo conforme NOM-151-SCFI-2016. Almacenamiento WORM en S3 Object Lock con retención mínima de 5 años.

  • Hash criptográfico SHA-256 por evento
  • Cadena Merkle: alterar 1 evento rompe todos los posteriores
  • S3 Object Lock con modo Compliance (no editable)
  • Sello de tiempo NOM-151 con servidor PSC autorizado
  • Exportable para juicio · cadena de custodia auditable

§ 02 metodología MCC™ methodology of certified conciliation
cuatro pilares

El framework Conciliación Certificada.

No es solo software — es una metodología propietaria aplicada en cada implementación. Cada pilar construido sobre tecnología enterprise probada y respaldada por estándares NOM y AWS.

1 identity first

Identity Resolution antes de Ingest

Resolver primero quién es quién. Cruzamos ID biométrico ↔ ID nómina ↔ CURP ↔ RFC ↔ ID interno antes de leer un solo evento de checada.

→ master data management · golden record
2 schema-agnostic

Schema-agnostic Storage

Apache Iceberg como capa de almacenamiento. Evolución de esquema sin migración, time travel para auditoría, compatibilidad con cualquier formato que la STPS termine pidiendo.

→ Apache Iceberg · AWS S3 · Glue Catalog
3 hash-chained

Hash-chained Evidence Vault

Cada registro se firma con hash SHA-256, encadenado al registro anterior, y timestamp del servidor conforme NOM-151. Valor probatorio absoluto.

→ NOM-151-SCFI-2016 · Merkle tree · S3 Object Lock
4 bidirectional

Bidirectional Outbound

No solo empujamos a nómina. También recibimos confirmación de payments para cerrar el loop. Discrepancias detectadas antes del juicio.

→ event-driven · webhooks · idempotent ops

§ 05 cómo cobramos modelo transparente
pricing transparente

Tres componentes. Cero sorpresas.

No publicamos precios exactos porque cada cliente tiene complejidad distinta. Pero sí publicamos cómo se compone el costo y qué incluye cada parte.

A setup

Implementación inicial

Pago único. Incluye discovery, identity resolution, conexión de fuentes iniciales, configuración de reglas LFT específicas, y go-live de los primeros sitios.

→ rango típico: 60–150 días-persona senior
B licencia anual

Por empleado activo

Cargo recurrente anual. Incluye actualizaciones de producto, soporte estándar, monitoreo, parches de seguridad, mantenimiento de conectores, MEDULAR AI ilimitado.

→ pricing por banda · 500–2k · 2k–10k · 10k+
C evidence vault

Almacenamiento certificado

Cargo mensual por empleado activo. Hash-chained storage, S3 Object Lock (WORM), retención configurable hasta 7 años, exportación inmutable para juicio.

→ retención mínima recomendada: 5 años
