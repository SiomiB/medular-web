§ 04 detalle técnico por categoría para tu equipo de IT
cómo lo conectamos

Lo que tu CTO necesita saber.

A tier 1 · API

Conector nativo

OAuth o API Key. Polling configurable (5-15 min). Webhook si el vendor lo soporta. Backfill histórico completo. Sin agentes en tu red.

→ outbound del sitio · solo HTTPS · sin firewall opening
B tier 2 · SDK

Edge Collector ligero

Contenedor Docker o binario Go. Corre on-prem en tu red. Se comunica con el biométrico vía SDK local. Sube eventos a MEDULAR vía HTTPS outbound.

→ ~50 MB RAM · 1 CPU · disk 5 GB · self-healing
C tier 3 · archivo

SFTP / S3 / drop folder

El sistema deja un archivo en SFTP, S3 bucket compartido, o carpeta de red. MEDULAR lo recoge, valida formato, parsea, y carga al pipeline.

→ CSV · TSV · XLSX · TXT · XML · JSON
D DB directa

Read-only replica

Si tu biométrico tiene DB accesible (SQL Server, MySQL, PostgreSQL), creamos read replica o usamos CDC. Cero impacto en performance del original.

→ Debezium · DMS · log-based CDC · pull mode
